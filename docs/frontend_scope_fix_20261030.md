# 2026-10-30：撤除后端 LUT 优化

依据最新答疑 C147.1，撤除 ABC9 后、map_cells 前的小范围 $lut 重构。旧 b035baf、旧 Windows 包及报告7/9只保留为历史，不能继续作为新候选的验收结果。

## 产品改动

- src/pmux_opt.cc：删除全部局部 LUT 分解、三 LUT 回退和输入排列规范化；删除 -lut 帮助及执行路径。旧 -lut 调用明确报错，防止旧流程误用。
- 保留同一 pass 的 pmux_opt -arith 和默认 pmux_opt；两者的前端算法正文未改。
- integration/apply_stable_pmux.py：新安装只加入前端两次调用；已有完整三调用版本升级时移除后端调用，支持 LF/CRLF，重复执行不重复接入；仍拒绝不完整接入。
- integration/yosys_0_69_stable_pmux.patch：移除后端调用；删除已失效的 yosys_0_69_local_lut.patch。
- 不调整原有 Yosys pass 的相对顺序，不修改 ABC、其他 pass 算法或测试 RTL。

## 验收状态

用户要求停止本地检测，直接推送删除版，由队友验收。本轮仅在该指令之前完成了安装器4项回归（LF/CRLF、新装、旧版迁移、重复执行及失败保护，均通过）；未取得新候选的九例面积、功能和效率结果。

旧版22.0203%及两轮Windows通过结论不得沿用到本候选。尚不能保证保留前端两种模式后达到20%或21%的面积目标。

## 队友接手

1. 按本次推送的完整提交构建。已有旧集成树使用：python integration/apply_stable_pmux.py --yosys-root <Yosys源码目录> --replace-existing。安装器会撤掉旧的 pmux_opt -lut 调用；不要叠加历史补丁。若源码中有非标准的手工接入，明确移除所有后端调用。
2. 核对答疑 C145 公布的基座（Yosys 0.69+24，d0e71cfb7-dirty）与实际构建的关系；原版和候选使用一致的基座、ABC及构建参数。旧版本基座为9f75ca1，不得直接宣称与新公布身份一致。
3. 全九例重新记录面积、LUT/NOT/DFF；逐例逻辑不能增加，九例降幅取算术平均。无论是否达到目标，都保留完整结果；原验收脚本的21%断言可能在低于目标时提前退出，仍需完成独立功能验证。
4. 按最新答疑执行EQY及负对照；C149给出按0初始化、EQY最终PASS要求，需核对模型和配置。原始RTL、模型、配置、日志与反例完整保留。
5. 同次采集墙钟和主Yosys峰值工作集，使用相同工具；按C132/C147/C148最新规定预热及复核。两轮数据不混用，不择优替换。
6. 通过后重打Windows包和哈希；按C152注明测试环境预装OSS CAD Suite的路径。

## 范围判断

本次保留的两种模式在ABC9前处理PMUX及其互斥分支，不属于C147.1点名禁止的后端LUT重构。这是对明确禁令的区分，不代表官方已逐条批准所有现有前端规则；C149第一问的笼统回答也不扩张解释为新的许可。

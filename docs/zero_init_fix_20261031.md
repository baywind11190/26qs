# 2026-10-31：零初态合同修正（当前候选）

针对报告10的三条反例修正。历史f3f5f2a不再作为功能验收通过版。

## 必须同时更新综合和证明脚本

对原版、候选使用完全相同的外部脚本，在原始RTL读取后、任何综合优化前明确未初始化寄存器的零初态：

```yosys
read_verilog -sv <原始RTL>
hierarchy -top <TOP>
proc
zinit -all
synth_intel -family cycloneiv -top <TOP>
```

proc只把原始过程转换成触发器和逻辑；zinit -all为未初始化触发器建立0初值，已知非零初值通过反相编码保持原逻辑含义，不把输入、组合X/Z置0。两侧均执行，完整耗时均包含这些步骤；synth_intel内部原有pass顺序不变。此预处理用于实现答疑C149的初态语义，不是新增面积优化步骤。

EQY gold侧也必须在原始RTL读入后先proc、zinit -all，再prep/优化。gate侧必须读取本次新综合的post-ABC网表，保留映射传播出来的init/power_up；不要用旧网表，不要在最终物理寄存器上再单独强行补0。器件模型保持真实high/low语义，不通过改模型或复位假设取PASS。遵循C54优先证明厂商映射前post-ABC网表。

## 产品源码改动

src/pmux_opt.cc只调整现有EnableFeedback::record的初值保护：原来仅允许未知初值，现允许未知或明确0初值，已知1仍跳过。重构保留原有触发器Q及init属性，只改经原结构条件验证的使能和D逻辑；后续标准综合据明确初值决定哪些状态位可以合并/常量化。必须配合上述统一初始化流程使用，不能只复制C++后沿用报告10的旧脚本。

旧版本在无初态约束时把gpioout[2/4/6]折为1；单纯提前初始化且不调整反馈规则，面积均值降到19.340235%。本次最小改动恢复可保持零初态的共享/反馈重构，避免以不保留初态的常量替换获取收益。后端LUT仍已删除，未改ABC或其他pass算法。

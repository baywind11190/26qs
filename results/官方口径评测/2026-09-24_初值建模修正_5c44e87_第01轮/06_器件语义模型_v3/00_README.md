## 目的（按用户指令）

1. **先用最小对照确认现有 EQY 对初值处理的三个问题**（`01_最小对照_初值处理/`）：
   - Q1：原始未声明初值（金侧自由）与映射后确定初值（门侧=0）并存时，未声明来源是否允许被确定化（对照金侧自由 vs 门侧自由）；
   - Q2：明确声明且两侧一致时应当通过；
   - Q3：明确声明且两侧冲突（0 vs 1）时应当被检出。
2. **按已核对的器件语义与实际网表参数实现 dffeas 形式模型 v3**（`02_model_v3/`）：
   - 器件语义来源：Quartus 13.0 `fv_lib/verilog/dffeas.v`（异步清零/置位与数据路径）与 `sim_lib/altera_primitives.v`（clrn 低=清零；上电 `power_up=="high"?1:0`）；
   - 实际网表统计（本轮 8 个 mapped 文件，共 493 个 dffeas）：`power_up` 全部 `"low"`；`prn=1'b1`、`sclr=sload=aload=asdata=1'b0` 恒为常量；`clrn` 为常量 1 或信号；**`ena` 大多为信号驱动**（test1 217/222、test3 全部、test4 1/10）；
   - 优先支持本轮实际使用的单元配置（`prn=1`、`sclr/sload/aload/asdata=0`、`power_up∈{low,high}`、`clrn/ena` 任意）；其余条件由 **预检阻断器** `precheck_supported_config.py` 明确阻断（不静默建模）。
3. **补充清零、使能、初值及相关控制优先级检查**（`03_模型检查/`），对照 v2 与 v3。
4. **用 v3 重跑四例受影响的功能证明**（`04_四例重跑/`），与第 03 轮（v1 口径）和 v2 重跑逐分区对照。

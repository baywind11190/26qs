# 01 前提可满足性审计（“检测到 x”与“已证明约束矛盾”分开记录）

- 范围：`tree/run01` 全部 **106 个分区**（四例 × 优化/基线两链），每个分区执行两个前提探针（DF / noDF）。
- 方法：探针 = 原 `run.ys` 的最终 sat 行替换为 `chformal -assert -remove` + `sat -seq 1 -set-init-undef [± -set-def-formal] -set-def-inputs -set-assumes miter`（无证明目标，直接求解前提的 SAT/UNSAT）。
- 判读：`SAT solving finished - no model found.` = **前提 UNSAT（约束矛盾已由求解器证明）**；`- model found:` = 前提 SAT。

## 2. 分开记录的核心结论

1. **“检测到 x”**：96/106 个分区（test1 80、test3 6、test4 10）的初值方程含 x；2 个分区无初值方程（test2）；其余 8 个（test1 三对、test3.rw 一对）无 x。
2. **“已证明约束矛盾”**：上述 96 个含 x 分区**逐一经 SAT 求解证明前提 UNSAT**（不是推断）——即在 DF 协议下这些分区的基例不可能被证伪（空证明）。
3. **两集合完全重合（在本套输入上）**：不存在“有 x 但前提 SAT”或“无 x 但前提 UNSAT”的分区；
   因此本套中“含 x”与“约束矛盾”可互换，但记录上严格分开（见 `audit_summary.csv` 的 `x_DF` 与 `probe_DF` 两列）。
4. **无 x 分区的前提均 SAT**（test1×3、test3.rw）——其证明/反例均为真实检查（rw 的真实 FAIL 见 04/05）。
5. **noDF 下前提全部 SAT（106/106）**：移除 `-set-def-formal` 后不存在任何空前提；结合 03 的检出能力对照，可排除“新空检查”。

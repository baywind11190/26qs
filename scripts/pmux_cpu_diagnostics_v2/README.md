# Windows test4 CPU诊断 v2

独立诊断入口，固定算法6862831。正式v6计分脚本、算法、旧v1及历史结果不修改。

`plan`只读；`run`固定60次普通CPU、3次工件捕获和证明、40次阶段CPU；`analyze --round`只读输出同数据逐对统计。无补样、无预热、无正式验收。进程通知及模块观察不保证穷尽；缺读保留null，进程分解与Job总量有效性分别标记。

普通观察器在目标Job外采集进程句柄，保留到退出后再读CPU；诊断ABC另将自身进程句柄复制给Yosys，以读取正常退出后的完整CPU。计分总量仍来自同一v6内部Job，ABC不重复相加。QPC墙钟与CPU分别保留。开关只作用于诊断版整个pass调用。

执行命令、保护上限和故障处理见资料目录第13号DeepSeek说明。系统跟踪是单独入口，在固定样本后按条件执行，不自动重跑正式验证。

# Windows 内部周期 CPU 小规模试验

独立方法 `windows-internal-cycle-cpu-pilot-v1`。正式 v6 没有切换方法。

2026-10-13 实测完成三个探针入口，发现退出子孙进程后的 Job 周期低于保留进程句柄合计的读取边界，结论为 **仅部分计量可行**。按批准的停止条件，没有构建实验 Yosys/ABC，没有执行四次真实综合。这里不包含已验证可用的综合计量后端。

`probe.cc` 是原生探针：硬件/结构/六段校准，小工作块/等待，受控子孙进程/句柄关闭。固定运算使用 100、1000、10000、100000 次迭代；每档三次。树核对使用无控制台的受控子孙进程，实际 Yosys 的启动方式未更改。`private_job.h` 从冻结 PHNT 类型构造完整 x64 结构；来源、提交、哈希和许可在 `source_refs`。

`pilot_windows.cmd plan` 只读已完成状态；`analyze` 只读现有原始 JSON 并在标准输出重算结论。该入口不编译、不测量、不启动正式验证。供 DeepSeek 使用的命令和后续边界见 [第12号执行说明](D:/codex/02_嵌赛/deepseek执行文件/12_内部高分辨率CPU小规模试验_执行说明.md)。

采用校准后的频率换算仅用于本机实验；原始周期全部保留。线程的微小读数不代表整个进程树具有相同准确度，不用于重新判定 5%。下一步须先解释 Job 快照与进程周期读数的更新边界及退出尾段；本入口不会自动继续或追加样本。

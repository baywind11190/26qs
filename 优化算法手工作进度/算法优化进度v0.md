# 7. Pattern A：shared-selector pair-swap

这是第一条真正重要的结构优化。

目标结构：

```text
多个 PMUX 共用 selector bank / control
两个 PMUX 的 branch 数据存在成对交换关系
```

重构：

```text
大规模重复 PMUX 数据网络
→ 较小 PMUX / shared structure
→ 最终 2:1 swap mux
```

支持：

```text
full-decode selector bank
shared control
same-width PMUX pairs
任意 swap bit
有限 special pair
profitability gate
```

H1 前稳定 gate：

```cpp
bool special_case_profitable =
    special_base_values.empty() ||
    (special_base_values.size() == 1 &&
     (pair_count >= 8 ||
      (pair_count == 4 &&
       info_a.width <= 2)));

bool profitable_pattern =
    swapped_pairs >= 2 &&
    swapped_pairs * 4 >= pair_count * 3 &&
    special_base_values.size() <= 1 &&
    special_case_profitable;
```

设计原则：

```text
不硬编码 cell name
从 control / selector / branch relation 出发
支持任意 swap bit
特殊 pair 保留
必须有 profitability
candidate != 必须 rewrite
```
